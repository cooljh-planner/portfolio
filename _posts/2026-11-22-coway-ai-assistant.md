## 개요

"현장 판매조직을 위한 LangGraph 기반 AI Agent"

AI 영업비서는 1만 명이 넘는 현장 판매인(코디)과 조직장이 복잡한 렌탈 규정, 수수료, 프로모션, 제품, 관리고객 현황을 자연어로 묻고 답을 얻는 대화형 AI Agent입니다. 모바일 앱 오픈을 시작으로 사내 포털 PC와 협력 판매 조직까지 순차적으로 넓혔으며, 로컬 LLM(Ollama, Gemma)·LangGraph PoC 구현 경험을 바탕으로 개발조직과 에이전트 아키텍처 및 데이터 파이프라인 설계를 검토하였습니다.

## 문제 정의

"환각 통제와 파편화된 사내 데이터 공급망의 부재"

영업 현장에서는 렌탈료나 수수료, 약정 답변이 조금만 어긋나도 잘못된 고객 안내와 민원의 원인이 될 수 있습니다. 단일 프롬프트 호출만으로는 최신 사내 정책 반영과 가격 누락·업무 외 질의 환각 통제가 어려웠으며, 문서·자사몰·그룹웨어·영업 시스템에 흩어진 데이터를 에이전트에 제때 공급할 통합 파이프라인이 필요했습니다.

## 해결 방향

"명시적 Node·Edge 설계와 하이브리드 데이터 파이프라인"

개발조직과 함께 에이전트의 처리 흐름(Graph)과 데이터 공급 책임을 명확히 구조화하는 데 집중하였습니다.

### 1. LangGraph 기반 Node·Edge 설계 및 시스템 프롬프트 협업

아키텍처 고도화 과정에서 중앙 에이전트가 도구를 직접 호출하는 단일 구조로 개편하며, **검색 계획·문서 검색 → 도구 호출 루프와 Reranker → 답변 생성 → 추천 질문 → 대화 기록**의 흐름에 입력 직후 병렬 가드레일을 결합하였습니다. 복수 모델 질의에는 임의 추정 대신 모델 선택 칩을 제시하는 HITL(진입 건 대부분이 단시간 내 선택 완료로 해소)을 두고, 프롬프트에 가격 기준 통일·메타데이터 차단·업무 외 질의 방어 규칙을 반영하였습니다.

### 2. 비정형(RAG)·정형(Tool Calling) 사내 데이터 파이프라인 개설

데이터 범위가 곧 답변 범위인 만큼 사내 문서 저장소와 GCS를 연동한 동기화 파이프라인을 신설하고, 원본 담당자 동기화 권한 관리와 조직별 접근 권한을 운영 어드민으로 통합하였습니다. 관리고객·추천은 실시간 API, 가격·수수료는 사내 DB, 규정·프로모션은 벡터 검색으로 경로를 나누고, 답변 내 모바일 주문 딥링크와 그룹웨어 프로모션 자동 수집(관리 항목을 대폭 세분화)을 연결하였습니다.

### 3. 채널·조직별 Scope 분기와 검증·관측 체계 정착

PC 사내망과 협력 판매 조직으로 확장하며 답변 데이터를 세분화된 권한(Scope) 체계로 분기해 어드민에서 허용·차단을 제어하였습니다. 오류·미해결 질의 로그 분리, 호출량 제어, 전용 인프라 분리를 적용하고, 반복 회귀 검증 자동화를 통해 대규모 테스트 케이스의 반복 회귀 검증 공수를 기존 수동 검증 대비 크게 단축했습니다.

## 회고 포인트

AI Agent 기획은 UI를 넘어 그래프 분기 조건, 프롬프트 경계, 데이터 공급 거버넌스를 함께 설계하는 일이었습니다. 누적 자연어 질의는 **약 13만 건 이상** 축적되었으며, 현장 판매인의 **절반 이상**이 서비스를 이용하고 단기 재방문율도 **약 30%대**를 유지하며 자연어 질의 활용 비중을 점진적으로 회복·안착시켰습니다.
